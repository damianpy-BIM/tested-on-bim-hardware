# ima2-gen

**What it is.** Local image generation studio with multi-provider support (GPT, Grok, Gemini, NovelAI, ComfyUI) featuring branching workflows and canvas editing

**Verdict: works.** ima2-gen 3.26.3 works on our server: the local ComfyUI lane (SD-Turbo) generates images through the web UI and the CLI on the RTX 3080; cloud lanes need paid keys.

**Hardware:** CPU only, on the NVIDIA Tesla V100 server
